ฟอร์มออกบิล
ลูกค้าด่วน:

ซิงค์บิลระหว่างคอมพิวเตอร์และมือถือ

เชื่อมต่อฐานข้อมูลฟรี (Firebase Firestore) เพื่อให้บิลที่บันทึกในคอมขึ้นบนมือถือทันที

ยังไม่ได้เชื่อมต่อ

วิธีตั้งค่าครั้งเดียว (~2 นาที):

  1. เข้าเว็บ console.firebase.google.com ด้วยบัญชี Gmail แล้วกด Create a project
  2. เข้าเมนู Build → Firestore Database กด Create database (เลือกโหมด Start in test mode)
  3. เข้าเมนู Build → Authentication กด Get started → เลือกเปิดใช้งาน Anonymous (กด Enable แล้ว Save)
  4. กดไอคอน ฟันเฟือง (Project settings) มุมซ้ายบน → เลื่อนลงมาที่ Your apps กดปุ่มไอคอนเว็บ </> → ตั้งชื่อแอปแล้วคัดลอกโค้ดส่วน { apiKey: "...", ... } มาวางด้านล่างนี้

เริ่มบิลใหม่ / ล้างรายการสินค้า?

ระบบจะล้างชื่อลูกค้า รายการสินค้า และตัวเลขทั้งหมด เพื่อให้คุณพร้อมกรอกข้อมูลสำหรับลูกค้าท่านถัดไปค่ะ

เพิ่มลูกค้าด่วน

ระบบจะบันทึกรายชื่อลูกค้าด่วนไว้ถาวร และซิงค์ขึ้นมือถือให้อัตโนมัติหากเชื่อมต่อไว้ค่ะ

กรุณาระบุชื่อลูกค้าก่อนค่ะ

รายการบิลที่บันทึกไว้

บันทึกถาวรในเบราว์เซอร์เครื่องนี้ • คลิก "เปิดบิลนี้" เพื่อนำกลับมาแก้ไขหรือพิมพ์

ยังไม่มีรายการบิลที่บันทึกไว้

กดปุ่ม "เก็บบิลนี้" เพื่อเก็บรายการบิลไว้ใช้งานและซิงค์ข้ามอุปกรณ์ค่ะ
